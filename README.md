# 赛事直播时移留存与回看上架

所有绝对时刻是同一试播历中的 UTC 小时；`offsets` 给区域在对应观察期的小时偏移。首播日期可跨当地日界。`rights` 区间为实际所许上架范围，不是日志采样结束时间；`coverage` 区间外未知。`view` 记录同一人连续看到的节目进度，进度单位分钟，`utc` 为该段开始，`program` 决定进度轴，`kind=merged` 无法区分直播还是回放，不能分成两次观察。回看完成口径是集齐指定全片进度；完整回看条件受授权窗口和不可播放片段共同限制。同一 `lane` 不可同时安排两档。`public_on` 代表已对外确认，`withdraw` 从事件时起终止被引用的权利，不追溯抹掉此前实际看过的片段。请求选择分析截止小时和完整观看目标人数。

## 数据包

`sample/` 是本地合成的业务记录，均为 UTF-8 CSV；`table-format.json` 给出各表的列顺序与标量类型，`str` 中 `-` 表示不适用，逗号分隔多值。不同表中同名业务标识用于关联，具体含义见上文。资料入口只检查表头和格式，不对业务状态作判断。

## 运行

使用 Python 3.11 标准库，不需要安装三方依赖。读取样例与运行资料检查：

```sh
python3 intake.py
python3 -m unittest discover -s tests -v
```

也可以将同格式的资料目录作为 `intake.py` 的位置参数。
